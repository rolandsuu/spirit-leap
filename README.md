# Spirit Leap

A tiny browser action game: help the Claude spirit hop between floating sky islands above the mist.

## Play

Open `index.html` in any modern browser. No build step or dependencies.

## Controls

- **Hold** mouse, touch, or Space to charge a leap. The ring fills, then swings back down if you hold too long.
- **Release** to leap.

## Rules

- +1 for each new block you land on.
- Land near the center for a **Perfect**; Perfects in a row stack a combo bonus.
- Skipping a block earns extra points.
- Grab sparks in mid-air for +1.
- Moss blocks stay put, blue blocks drift up and down (from 4 points), amber blocks crumble a second after you land (from 9 points).
- Fall into the mist and the run ends. Your best score is saved in the browser.
